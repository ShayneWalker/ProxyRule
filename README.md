# rule

代理软件规则仓库，按代理软件和规则名称分类维护。当前提供 Surge 和 Quantumult X 的红果短剧、红果漫剧广告域名拦截规则。

## 规则目录

| 代理软件 | 规则 | 功能 | 使用说明 |
| --- | --- | --- | --- |
| Surge | hongguo-ads | 拦截部分红果广告及相关 SDK 请求 | [查看配置方法](./Surge/hongguo-ads/README.md) |
| Quantumult X | hongguo-ads | 拦截部分红果广告及相关 SDK 请求 | [查看配置方法](./QuantumultX/hongguo-ads/README.md) |

两个版本各包含 22 条域名规则，覆盖部分穿山甲广告联盟、字节广告投放及 SDK 接口。各版本使用对应软件的原生格式，请选择与你使用的软件一致的版本。

## 使用方法

1. 从上表进入对应软件的规则说明。
2. 在说明中选择 GitHub Raw 或 jsDelivr CDN 地址，按示例添加远程订阅；两种地址任选其一。
3. 保存配置并更新资源，确认规则已启用，目标应用流量经过代理软件。
4. 结合请求记录检查规则是否命中，并确认登录、播放等功能是否正常。

具体配置段、策略和停用方法以各规则文件夹内的 `README.md` 为准。规则内容更新后需由客户端更新远程资源，CDN 可能存在缓存延迟。

```text
rule/
├── README.md

│   └── hongguo-ads/
│       ├── README.md
│       └── hongguo-ads.list
└── QuantumultX/

```

根目录按代理软件划分，每个规则使用独立文件夹，文件夹内包含规则文件及配套 `README.md`。新增规则时沿用此结构，订阅路径与实际目录保持一致。

## 使用边界

当前规则尚未通过实际客户端流量验证，不能保证移除全部广告，也不提供跳过广告验证、解锁付费内容或领取激励奖励的能力。

域名规则不限定应用，其他应用访问相同域名时也会被拦截。部分通用 SDK 接口可能影响登录、内容加载等功能。若出现异常，先停用对应规则，对比应用表现，再结合请求记录排查。
